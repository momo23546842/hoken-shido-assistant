# AI評価用データ

AIが面談メモから「食べたものと量」「運動と時間」を正しく読み取れるかを測るための、**架空の**面談メモと正解です。実在の人物や面談とは関係ありません。
今は17例です（C01〜C12はAさん、C13〜C17はBさんの生活をもとにしています。対象者の設定は [docs/persona.md](../docs/persona.md) にあります）。

## ファイル

- `cases.csv`：プログラムで使うデータ。1行が1例で、正解（`expected_json`）はJSONの形で入れています
- この README：人が読むための一覧（下の表）

## 作り方の方針

- 1つの例で、1つの「AIが間違えやすい点」を試す（おかわり、残した、やめた、頻度、予定、量がわからない、など）
- 正解には、メモに書いてある量の言い方（「茶碗1杯」など）と、その数を入れる
- グラム数（`grams`）は空けている。目安量の表（#7）ができてから、その表で計算して入れる
- メモに量が書いていない食品は、正解も「量不明」にする。AIが量を勝手に作らないかを試すため
- 運動には、「今やっている」か「予定」かの印を付ける

## これから

- 技術検証（#9）のときに、開発者が実際の面談を想定して書いた架空のメモを足す
