# 根拠資料の一覧

このアプリが計算やルールの根拠として使う資料と、その利用条件をまとめます。

## 1. 食事のカロリー

### 日本食品標準成分表（八訂）増補2023年

| 項目 | 内容 |
| --- | --- |
| 作成 | 文部科学省 科学技術・学術審議会 資源調査分科会 |
| 版 | 八訂 増補2023年（令和5年4月）。2026年5月時点で最新（国立国会図書館の案内による） |
| 入手先 | https://www.mext.go.jp/a_menu/syokuhinseibun/index.htm （全文PDFとExcelデータ）<br>食品成分データベース：https://fooddb.mext.go.jp/ |
| 使う内容 | 食品ごとの、可食部100gあたりのエネルギー（kcal） |
| 利用条件 | 文部科学省のページに「食品成分データは、ご自由に利用して頂けます」とある。アプリなどで二次利用するときは、出典を書く |
| 出典の書き方 | 「日本食品標準成分表(八訂)増補2023年から引用」（文部科学省が指定している書き方） |
| 補足 | 文部科学省ウェブサイト利用規約では、数値データは著作権の対象ではなく自由に使えるとされている。そのほかのコンテンツも、出典を書けば商用も含めて利用でき、CC BY 4.0 と互換性がある |

### 目安量（「お茶碗1杯＝何g」など）

| 項目 | 内容 |
| --- | --- |
| 使う資料 | 国立健康・栄養研究所「『栄養摂取状況調査のための標準的図版ツール（2009年版）』に基づく重量目安表（2009年版）」 |
| 入手先 | https://www.nibiohn.go.jp/eiken/chosa/pdf/jyuryomeyasuhyo2009_2013ver.pdf |
| 使う内容 | 「茶碗1杯」「1切れ」などの言い方を、グラムに置きかえる目安 |
| この資料を選んだ理由 | 国の「国民健康・栄養調査」で、食べた量を調べるために作られた公的な資料だから |
| 利用条件 | PDFとサイトに明記なし。数値は出典を書いて使い、表そのものは転載しない |

## 2. 運動で使うカロリー

### 身体活動のメッツ（METs）表

| 項目 | 内容 |
| --- | --- |
| 使う資料 | 改訂第2版「身体活動のメッツ（METs）表」成人版（2024年、日本語版：産業技術総合研究所 中江悟司氏、医薬基盤・健康・栄養研究所 吉村英一氏・小野玲氏）。原典は Compendium of Physical Activities（https://pacompendium.com/） |
| 入手先 | https://pacompendium.com/wp-content/uploads/2024/11/2024compendium_adult_japanese-2.pdf |
| 使う内容 | 活動ごとのメッツの値 |
| この版を選んだ理由 | 最新の版で、収録された活動が多い（821個→1111個） |
| 利用条件 | 成人版は商用目的でも無料で使える。MET値を変えたり、MET値の違う活動をまとめたりしない。出典としてCompendiumのウェブサイト（https://pacompendium.com/）か論文を書く |

### 消費カロリーの計算式

| 項目 | 内容 |
| --- | --- |
| 使う式 | (メッツ − 1) × 体重（kg） × 時間（h） × 1.05 |
| 出典 | 厚生労働省「保健指導における学習教材集」（無理なく内臓脂肪を減らすために）<br>https://www.mhlw.go.jp/bunya/kenkou/seikatsu/pdf/ikk-a10.pdf |
| この式を選んだ理由 | 減量の見込みを出すには、ふだんより多く使った分だけが知りたいので、安静時の分（メッツの「1」）を引く式が目的に合っている |
| 参考 | メッツ表 改訂第2版（2024年）の説明には、安静時を引かない式（メッツ × 体重 × 時間）が書かれている。このアプリでは使わない |

| 資料 | 作成・版 | 入手先 | 使う内容 |

| 特定健康診査・特定保健指導の円滑な実施に向けた手引き | 厚生労働省、第4.3版（2026年3月9日公表） | https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/handbook_31132.html | 積極的支援・動機付け支援、評価のしくみ |

| 第4期の特定保健指導の評価体系（検討会資料） | 厚生労働省 | https://www.mhlw.go.jp/content/10904750/001019475.pdf | 2cm・2kg＝180ポイント、そのほかのアウトカム評価とプロセス評価のポイント |
| 特定健康診査・特定保健指導に関するQ&A集 第4期 | 厚生労働省 | https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000161103.html （一覧ページ） | 細かいルールの確認 |

【決めたこと】検討会資料では、2cm・2kgの目標に「※当該年の健診時の体重の値に、0.024を乗じた体重（kg）以上かつ同体重と同じ値の腹囲（cm）以上減少している」という注があります。このアプリはポートフォリオのため、判定は「お腹まわり2cm以上・体重2kg以上」だけで行い、この注は入れません。

### 厚生労働省の資料の利用条件

- 厚生労働省ホームページのコンテンツは、特に書かれていない限り「公共データ利用規約（第1.0版）」（PDL1.0）にしたがって利用できる
- 出典の書き方の例：「出典：『○○』（厚生労働省）（ページのURL）（○年○月○日に利用）」
- 加工して使う場合は、加工したことも書く（例：「『○○』（厚生労働省）（URL）を加工して作成」）。国が作ったように見せてはいけない
- 冊子やガイドラインなどで、ほかの人が著作権を持っている部分は、その人の利用条件を確認する必要がある
