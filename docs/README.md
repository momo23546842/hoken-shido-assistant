# docs フォルダの構成

開発の資料をここにまとめます。

| 場所 | 内容 |
| --- | --- |
| `requirements.md` | 要件定義書（目的、利用者、課題、作るもの・作らないもの） |
| `persona.md` | 架空の利用者「田中さん」の設定 |
| `glossary.md` | 用語集（特定保健指導、SOAP、メッツなど） |
| `references.md` | 根拠資料の一覧（出典・版・利用条件） |
| `rules.md` | 計算ルールと安全ルール（根拠付き） |
| `development.md` | 開発環境、ブランチ運用、フォルダ構成 |
| `design/` | 業務フロー、画面設計、ER図、API設計 |
| `adr/` | 技術選定の記録（何を、なぜ選んだか） |
| `devlog.md` | 開発ログ |
| `../eval/` | AIの評価用データと結果 |
