# docs フォルダの構成

開発の資料をここにまとめます。

| 場所 | 内容 |
| --- | --- |
| `requirements.md` | 要件定義書（目的、利用者、課題、作るもの・作らないもの） |
| `glossary.md` | 用語集（特定保健指導、SOAP、メッツなど） |
| `persona.md` | 架空の対象者「Aさん」「Bさん」の設定 |
| `workflow.md` | 改善前・改善後の業務フロー図 |
| `references.md` | 根拠資料の一覧（出典・版・利用条件） |
| `rules.md` | 計算ルール（根拠付き） |
| `screens.md` | 画面一覧 |
| `wireframes/` | 各画面のワイヤーフレーム |
| `er.md` | ER図（データベースの設計） |
| `api.md` | API設計（画面とサーバーのやりとり） |
| `adr/` | 技術選定の記録（何を、なぜ選んだか） |
| `development.md` | ブランチ運用、作業の流れ、フォルダ構成 |
| `devlog.md` | 開発ログ |
| `../eval/` | AIの評価用データ |
