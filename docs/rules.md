# 計算ルール

保健指導アシスタントアプリが行う計算のルールです。
計算はすべてプログラムのルール（`lib/domain/`）で行い、AIには数値を作らせません。
出典の詳しい情報は [根拠資料の一覧](references.md) にあります。

## 1. 食事のカロリー

```
食事のカロリー（kcal）＝ 成分表の可食部100gあたりのエネルギー（kcal）× 重さ（g）÷ 100
```

- 重さは、目安量の表（「茶碗1杯」など）から出すか、担当者が入力する
- 商品は、パッケージに表示されているカロリーを、担当者が入力できる。そのときは、根拠として「パッケージの表示」と表示する
- 出典：日本食品標準成分表（八訂）増補2023年、重量目安表（2009年版）

## 2. 運動で使うカロリー

```
運動で使うカロリー（kcal）＝（メッツ − 1）× 体重（kg）× 時間（h）× 1.05
```

- 安静にしているときの分（1メッツ）を引いて、ふだんより多く使った分だけを出す
- メッツの値は表のまま使い、変えたり、平均したりしない
- 出典：保健指導における学習教材集（式）、改訂第2版「身体活動のメッツ（METs）表」成人版（メッツの値）

## 3. 体重が減る見込み

```
減る体重の見込み（kg）＝ 1日に減らすカロリー（kcal）× 日数 ÷ 7,000
```

- 1日に減らすカロリーは、食事で減らすカロリー（やめる・置きかえる食品の差）と、予定の運動で使うカロリーの合計
- 出典：体脂肪1kg＝約7,000kcal（健康づくりのための身体活動・運動ガイド2023 情報シート）

## 4. 1日に減らすカロリー（減らしたい体重からの逆算）

```
1日に減らすカロリー（kcal）＝ 減らしたい体重（kg）× 7,000 ÷ 日数
```

- 例：3か月（90日）で1kg減らしたい場合、1 × 7,000 ÷ 90 ＝ 77.7… → 約80kcal

## 5. 期間

- 3か月は90日として計算する

## 6. 今の運動と予定の運動

- 今やっている運動：今の生活で使っているカロリーとして表示する
- これからやる予定の運動：体重が減る見込み（3）の計算に使う

## 7. 数字の丸め方

- 計算の途中では丸めず、画面に表示するときだけ丸める
- カロリー：一の位を四捨五入して、10kcal単位で表示する（例：77.7kcal → 80kcal、163kcal → 160kcal）
- 体重：小数第2位を四捨五入して、小数第1位まで表示する
