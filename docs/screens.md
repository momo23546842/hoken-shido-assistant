# 画面一覧

要件定義書（`docs/requirements.md`）の「7. 必ず作るもの」をもとにした、画面の一覧です。
このアプリは対象者の情報を保存しないため、対象者の一覧や詳細の画面はありません。

## 画面の流れ（指導担当者）

```
ログイン → 面談画面 → SOAPの下書き → （コピーしてカルテに貼る）
```

## 画面の一覧

| No. | 画面 | 使う人 | この画面でできること |
| --- | --- | --- | --- |
| 1 | ログイン | 全員 | ログインする。ゲストログイン（登録しなくても、架空のデータで試せる） |
| 2 | 面談画面 | 指導担当者 | 面談しながら使う画面。下の「面談画面の中身」を参照 |
| 3 | SOAPの下書き | 指導担当者 | 面談のあとに使う。SOAPの形の下書きを見て、文章を直し、コピーする |
| 4 | 管理 | 管理者 | 指導担当者の登録。目安量の表などの根拠データの管理 |

## 面談画面の中身

面談中は画面を行き来しなくてすむように、メモから目標までを1つの画面にまとめます。

| 場所 | できること |
| --- | --- |
| 右側 | 面談しながらメモを打ち込む。面談で聞いた直近の体重とお腹まわりを入力する。氏名など、個人を特定できる情報を書かないよう、注意を表示する |
| 左側：読み取り結果 | 「AIで整理する」ボタンを押すと、AIが整理した「食べたものと量」「運動と時間」が出る。間違っていれば、成分表の食品の候補から選び直したり、量を直したりできる。商品は、パッケージのカロリーを手で入力できる |
| 左側：計算結果 | 食事のカロリーと、運動で使うカロリー。それぞれの計算の根拠（成分表の食品名、目安量、メッツの値、「パッケージの表示」など）も表示する |
| 左側：目標と見込み | メモに書いた目標（やめる・置きかえる食品、予定の運動）をAIが読み取り、1日に減らせるカロリーと、体重が減る見込みを出す。間違っていれば直せる。期間は入力する |

## 作業中の内容の一時保存

- 作業中のメモや計算結果は、担当者ごとに一時的に保存する。ブラウザが閉じても、もう一度開けば続きから使える
- 対象者の氏名などは保存しない
- SOAPをコピーし終わったとき、または一定の時間がたったときに、自動で消す（時間はER図・API設計のときに決める）

## 体重とお腹まわりについて

- 面談で聞いた直近の体重とお腹まわりを、面談画面で入力する
- 体重は、運動で使うカロリーの計算に使う
- 体重とお腹まわりは、SOAPの下書きの数値（O）に入れる
- 健診の結果や前回の記録は、今までどおりカルテで確認する
