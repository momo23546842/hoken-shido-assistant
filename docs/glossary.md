# 用語集

このポートフォリオに出てくる言葉を、保健や医療を知らない人にもわかるように説明します。

## 制度・仕事に関する言葉

| 用語 | 説明 |
| --- | --- |
| 特定健康診査（特定健診） | 40〜74歳の人を対象に、メタボリックシンドロームに注目して行う健康診断です。会社や市区町村で受ける、毎年の健康診断のことです。 |
| 特定保健指導 | 特定健診の結果、生活習慣病になるリスクが高いとわかった人に、管理栄養士や保健師が生活習慣の見直しをサポートする国の制度です。このアプリは、この制度の面談で使います。 |
| メタボリックシンドローム | お腹まわりに内臓脂肪がたまり、さらに血圧・血糖・血液中の脂質のうちいくつかが基準を超えている状態です。放っておくと、糖尿病や心臓・脳の病気につながりやすくなります。 |
| 積極的支援 | 特定保健指導のうち、リスクが多い人向けのコースです。最初の面談のあと、約3か月、続けてサポートします。 |
| 動機付け支援 | 特定保健指導のうち、リスクが比較的少ない人向けのコースです。最初の面談で目標を立て、約3か月後に結果を確認します。 |
| 対象者 | 特定保健指導を受ける人です。このアプリを直接は使いません。 |
| 指導担当者 | 面談を行う管理栄養士や保健師です。このアプリを主に使う人です。 |
| 初回面接 | 特定保健指導の最初の面談です。生活の様子を聞き取り、対象者と一緒に目標を決めます。このアプリが主に使われる場面です。 |
| アウトカム評価 | 「実際に成果が出たか」で評価するしくみです。2024年度から始まりました。代表的な目標は「お腹まわり2cm・体重2kgを減らすこと」で、達成すると特定保健指導を終えられます。 |
| プロセス評価 | 「どれだけサポートしたか」（面談や電話の回数など）で評価するしくみです。成果が出きらなかった場合は、アウトカム評価と合わせて点数（ポイント）を数えます。 |
| 2cm・2kg | アウトカム評価の代表的な目標で、「お腹まわり2cm以上、体重2kg以上を減らすこと」です。 |

## 食事・運動の計算に関する言葉

| 用語 | 説明 |
| --- | --- |
| カロリー（kcal） | 食べ物から取るエネルギーや、体を動かして使うエネルギーの量を表す単位です。 |
| 日本食品標準成分表 | 国（文部科学省）が出している、食品ごとの栄養素のデータです。食べられる部分100gあたりの値がのっています。このアプリは、カロリーの計算にこのデータを使います。 |
| 目安量 | 「お茶碗1杯」「食パン1枚」のような、ふだんの言い方での量を、グラム数に置きかえるための目安です。面談では対象者がグラムで話すことはほとんどないため、この置きかえが必要です。 |
| 早見表 | よく出る食品のカロリーをまとめた一覧です。指導担当者が手元に置いて使います。のっていない食品が出てくると、調べ直す必要があります。 |
| メッツ（METs） | 運動や家事など、体を動かす強さを表す単位です。静かに座っている状態を1として、その何倍のエネルギーを使うかで表します。たとえば、ふつうに歩くのは約3メッツです。 |
| メッツ表 | いろいろな活動のメッツの値をまとめた表です。このアプリは、運動で使うカロリーの計算にこの表を使います。 |
| 体脂肪1kg＝約7,000kcal | 体脂肪を1kg減らすのに必要なエネルギー量の目安です。食事で減らしたカロリーと運動で使ったカロリーの合計から、体重がどれくらい減りそうかを計算するときに使います。 |
