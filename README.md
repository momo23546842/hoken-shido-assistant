# hoken-shido-assistant

> 🚧 開発中です（2026年11月開始）

特定保健指導の面談メモから、食事と運動を根拠のあるデータ（日本食品標準成分表・メッツ表）で数値化し、無理のない減量目標と、SOAP形式の記録の下書きまでを作る、管理栄養士・保健師向けのWebアプリです。

## 一言でいうと

面談で聞いた「ご飯お茶碗1杯とおかわり」「通勤で歩くのは10分くらい」を、根拠のあるデータで自動的にカロリーに変換し、安全に成果が出る目標づくりを支援します。

## 大事にしていること

- **AIに数字を作らせない**：AIは話し言葉の整理だけを担当し、栄養価や消費エネルギーは公的なデータと計算式で求めます
- **決めるのは人**：AIが出すのは下書きと候補まで。目標は専門家と本人が決めます
- **実在の個人データは使わない**：デモはすべて架空の人物のデータです

## 予定している技術構成

TypeScript / Next.js / PostgreSQL / Prisma / LLM API / AWS

詳しい内容と選定理由は、開発の進行に合わせて追記します。
